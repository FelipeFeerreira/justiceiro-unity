# Justiceiro — Arena Shooter Prototype

A fast-paced first-person shooter prototype set in a fictional hillside
environment, where **level geometry, visual assets and sound effects are
generated by code** instead of imported art.

## What it demonstrates

- Movement feel: double-jump, sprint and rechargeable dashes.
- Combat: four weapon types with projectiles and area damage.
- Encounters: enemy archetypes, arena waves, key-gated progression and a boss.
- Procedural content: meshes, textures and synthesized runtime sound effects.
- Editor automation that rebuilds the level and main menu from code.

## Open the project

1. Install the editor version recorded in `ProjectSettings/ProjectVersion.txt`
   through Unity Hub.
2. Add this repository as a project and let Unity restore the packages listed in
   `Packages/manifest.json`.
3. Use **Justiceiro → Abrir Fase** in the editor to open or generate the demo
   scene. If the level is missing, use **Justiceiro → Reconstruir Fase**.
4. Enter Play mode.

Scene-building commands generate or replace scene content. Run them on a fresh
clone before customizing the levels.

## Code structure

```
Assets/Scripts/   Player, Weapons, Enemies, Level, Core, UI
Assets/Editor/    Procedural art and level/menu builders
```

The repository includes `Assets`, `Packages` and `ProjectSettings`. Unity caches,
local editor state and compiled builds are excluded and regenerate on import.

## Project status

This is a development prototype and code portfolio, not a released game. The
systems above were identified in the source; a fresh editor import, playthrough
and platform build have not been verified during this publication pass. See
[verification notes](docs/PORTFOLIO_VALIDATION.md). No performance or
release-readiness claims are made.
